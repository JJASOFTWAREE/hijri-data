# hijri-data

بيانات عامة يقرأها تطبيق «أيام». لا تضع هنا كود التطبيق ولا أي بيانات شخصية.

- `sighting.json`: تصحيحات بدايات الشهور بالرؤية بعد إعلان المحكمة العليا.
- `school.json`: التقويم الدراسي الرسمي لوزارة التعليم.

طريقة تعديل كل ملف في `data/README_AR.md` داخل مستودع التطبيق. التطبيق يتجاهل أي ملف مكسور ويحتفظ بآخر نسخة سليمة.

## المراقب

`.github/workflows/watch.yml` يقرأ كل ساعة عناوين الأخبار الرسمية (وكالة الأنباء السعودية ووزارة التعليم) عن رؤية الهلال والتقويم الدراسي. إذا ظهر خبر جديد مطابق فتح «Issue» هنا لينبّه المالك. **لا يعدّل أي ملف بيانات**؛ النشر ينتظر موافقة المالك. سجله في `watch/`. إذا تعذّرت قراءة الأخبار يعيد المحاولة، ولا يفشل التشغيل (فيصل بريد GitHub) إلا بعد 6 ساعات متتالية بلا قراءة؛ العدّاد في `watch/fails.json`.
